TURN LIGHTING

Player colors

Each player's turn sets every light they drive. Use the plans below for a different color or effect per light, or set one color for the whole player here — “Use picked” takes the color from the wheel on the Lights tab.

    PER LIGHT

    Light plans

    One row per light, per player. Turn a light off to leave it alone on that player's turn; an effect runs for as long as that turn lasts.

    GAME MOMENTS

    Moment lighting

    What the lights do when life changes, a commander is revealed or burned, players walk out, and the first player is picked. Tap a moment's name to switch it on or off. Changes save as you let go, and Test plays it on the room now.

    SEQUENCES

    Sound & timing

    Volumes and timings for the table's sequences. Changes save as you let go and reach the table screen within a few seconds. A volume above 100% boosts the clip past its recorded level.

    TABLE SCREEN

    Settings

    How the table screen itself behaves. Changes save as you let go and reach the table screen within a few seconds.
